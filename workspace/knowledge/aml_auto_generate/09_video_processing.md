# 视频处理与动作识别基础

## 概述

视频动作识别（Video Action Recognition）是计算机视觉的重要方向，目标是从视频中识别人物执行的动作类型。根据是否需要训练，主要分为两条技术路线：

1. **基于深度学习的端到端方法**（需要训练）：如 TSN、I3D、SlowFast、Video Swin Transformer 等
2. **基于骨架/姿态的规则方法**（无需训练）：通过预训练姿态估计模型提取关键点，再用规则或传统机器学习分类

对于"不需要训练"的约束，推荐路线 2。

## 视频获取工具

### yt-dlp

`yt-dlp` 是目前最活跃的 YouTube 视频下载工具，支持数千个视频平台。

安装：`pip install yt-dlp`

常用参数：
- `-f "bestvideo[height<=720]+bestaudio/best"` 控制画质
- `--merge-output-format mp4` 合并为 MP4
- `-o "%(id)s.%(ext)s"` 指定输出文件名模板
- `--cookies-from-browser chrome` 使用浏览器 cookie（处理受限视频）

### Google Drive 视频

部分数据集可能使用 Google Drive 链接：
- 可用 `gdown` 库下载：`pip install gdown`
- `gdown.download(url, output, fuzzy=True)`

## 视频帧提取

使用 OpenCV 进行视频帧提取是最通用的方案：

关键参数：
- `CAP_PROP_FPS`：获取视频原始帧率
- `CAP_PROP_FRAME_COUNT`：总帧数
- `CAP_PROP_FRAME_WIDTH/HEIGHT`：分辨率

帧采样策略：
- **均匀采样**：每隔固定帧数取一帧，适合短视频
- **关键帧采样**：检测场景变化或运动量突变的帧
- **滑窗采样**：固定窗口大小（如 30 帧），滑动步长取重叠窗口

对于动作识别，建议采样率 5-10 fps，保证能捕捉到动作的周期性特征。

## 视频预处理

- **缩放**：统一缩放到 640x480 或 320x240，加速处理
- **裁剪**：如果人物只占画面一部分，可先做人体检测再裁剪
- **时间对齐**：不同视频的时长差异较大，需要标准化处理长度

## 运动特征提取

从视频帧中提取运动信息的常见方法：

1. **光流法**：计算相邻帧之间像素的运动方向和幅度（Farneback、Lucas-Kanade）
2. **帧差法**：相邻帧差分检测运动区域
3. **骨架关键点轨迹**：使用姿态估计模型提取人体关键点的时间序列，分析运动模式

方法 3 最适合"不训练"的动作分类场景，因为预训练姿态模型（如 MediaPipe）已经能提供高质量的关键点，后续只需分析关键点的运动学特征。

## 数据格式与流水线设计

典型的视频动作分类流水线：

```
输入：视频URL / 文件路径
  ↓
1. 视频获取（yt-dlp / 本地读取）
  ↓
2. 帧采样（OpenCV，5-10 fps）
  ↓
3. 人体姿态估计（MediaPipe Pose）
  ↓
4. 关键点轨迹提取（时间序列）
  ↓
5. 运动学特征计算（频率、幅度、方向）
  ↓
6. 分类决策（规则 / 阈值）
  ↓
输出：动作类别 + 置信度
```
