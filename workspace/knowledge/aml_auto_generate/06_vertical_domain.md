# 垂直领域大模型

## Med-PaLM（医疗）
- **论文**：《Med-PaLM: A Large Language Model for Medicine》
- **核心**：基于PaLM微调，训练数据含医学论文、病历、指南。医学资格考试达医生水平。

## BioBERT（生物医学）
- **论文**：《BioBERT: a pre-trained biomedical language representation model》
- **核心**：PubMed语料微调，支持生物医学文本分类、命名实体识别、关系抽取。

## FinBERT（金融）
- **论文**：《FinBERT: Financial Sentiment Analysis with Pre-trained Language Models》
- **核心**：金融新闻/财报/研报语料微调，支持金融情感分析、市场趋势预测。

## LawGPT（法律）
- **论文**：《LawGPT: A Large Language Model for Legal Services》
- **核心**：法律法规、案例、法律文书数据，支持法律问答、合同生成与审查。

## EduGPT（教育）
- **论文**：《EduGPT: A Large Language Model for Education》
- **核心**：教材/教案/题库数据微调，支持知识点讲解、习题生成、个性化辅导。

## ChemBERTa（化学）
- **论文**：《ChemBERTa: A Large Language Model for Chemical Text Mining》
- **核心**：化学分子结构文本序列训练，支持分子性质预测、化学反应生成。

## GeoGPT（地球科学）
- **论文**：《GeoGPT: A Large Language Model for Geoscience》
- **核心**：地质报告、气象数据、遥感影像文本。气象预测、地质灾害预警。

## NewsGPT（新闻）
- **论文**：《NewsGPT: A Large Language Model for News Generation and Analysis》
- **核心**：新闻报道/时事评论数据，新闻稿生成、热点分析、多语言翻译。

## DesignGPT（设计）
- **论文**：《DesignGPT: A Large Language Model for Design and Creativity》
- **核心**：融合文本与视觉数据，设计理念生成、图文结合建议。

## AgricultureGPT（农业）
- **论文**：《AgricultureGPT: A Large Language Model for Agricultural Applications》
- **核心**：农业技术手册、病虫害防治、土壤气候数据。种植指导、病虫害诊断。
