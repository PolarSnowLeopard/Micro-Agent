# 推理与代码大模型

## Chain-of-Thought
- **论文**：《Chain-of-Thought Prompting Elicits Reasoning in Large Language Models》
- **核心**：思维链提示（CoT），分步推理示例激发逻辑推理能力，数学推理准确率提升30%以上。

## GPT-4
- **论文**：《GPT-4: Advanced Reasoning and General Capabilities》
- **核心**：多步推理与自我校正机制，处理复杂数学计算、逻辑推理、代码生成。

## CodeLlama
- **论文**：《CodeLlama: Open Foundation Models for Code》
- **模型**：Meta CodeLlama（7B/13B/70B）
- **核心**：基于LLaMA微调，代码生成/补全/解释，支持Python、C++等多语言。

## StarCoder
- **论文**：《StarCoder: A State-of-the-Art LLM for Code》
- **模型**：Hugging Face StarCoder
- **核心**：159种语言代码数据训练，代码注释对齐技术提升可读性。

## WizardCoder
- **论文**：《WizardCoder: Empowering Code LLMs with Evol-Instruct》
- **核心**：Evol-Instruct指令进化技术，代码生成基准超越CodeLlama。

## MathGPT
- **论文**：《MathGPT: Solving Mathematical Problems with LLMs》
- **核心**：数学符号理解与公式推理模块，从小学到大学数学题，分步讲解。

## PAL
- **论文**：《PAL: Program-aided Language Models》
- **核心**：LLM生成代码解决复杂问题（数学计算、数据分析），执行代码获取精确结果。

## ReAct
- **论文**：《ReAct: Synergizing Reasoning and Acting in Language Models》
- **核心**：推理-行动循环框架，推理过程中调用工具（搜索引擎、计算器）获取信息。

## CodeGen
- **论文**：《CodeGen: An Open Large Language Model for Code with Multi-Turn Generation》
- **模型**：Salesforce CodeGen
- **核心**：多轮代码生成与补全，根据自然语言描述生成代码。

## LogicGPT
- **论文**：《LogicGPT: Logical Reasoning via Symbolic Execution》
- **核心**：融合符号执行的逻辑推理，自然语言转逻辑表达式，减少推理幻觉。
